# Iteration 1 - Retrospective

## What went well

- We managed to complete several user stories during this iteration.
- We adapted our initial plan when we realised that some tasks were more complex than expected.
- We added a new user story, [Browse the main navigation pages (#58)](https://github.com/MESW-LES-2627/les-project-group-1/issues/58), which was simpler to implement and successfully completed within the iteration.

## What did not go well

- We initially planned too many user stories for the time available.
- We underestimated the complexity and effort required for some tasks, particularly [Memorabilia listing (#33)](https://github.com/MESW-LES-2627/les-project-group-1/issues/33) and [Memorabilia listing review (#34)](https://github.com/MESW-LES-2627/les-project-group-1/issues/34).
- As a result, we were unable to complete these two user stories within the iteration.

## What we will change in the next iteration

- Be more realistic when selecting user stories, taking into account the team's capacity and the time available.
- Estimate the complexity and effort of each user story more carefully before committing to it.
- Break down larger or more complex user stories into smaller tasks whenever possible.
- Discuss potential difficulties earlier and adjust priorities when necessary.
