# Assist Club - Definition of Done

A User Story is considered done when:
1. All acceptance criteria are met and demonstrated.
2. Code is reviewed and approved by at least one other developer.
3. Automated tests are written for the new logic (especially bidding, payments and auction closing), and CI passes.
4. The feature is tested locally by the author and verified by a second developer.
5. Database migrations are backward compatible and run cleanly on staging.
6. Docs are updated where needed (API, runbook, env vars, user-facing text).
